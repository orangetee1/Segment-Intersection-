# Geometry: 3D Segment Intersection

## Постановка задачи

Даны два отрезка в трёхмерном пространстве $\mathbb{R}^3$, каждый из которых задан парой точек:
$$S_1 = [A, B], \quad S_2 = [C, D]$$

Требуется найти пересечение отрезков с настраиваемым допуском.

---

## Архитектурные решения

### 1. Типобезопасный результат

```cpp
using IntersectionResult = std::variant<std::monostate, Vector3D, Segment3D>;
```

- `std::monostate` — пересечение отсутствует;
- `Vector3D` — пересечение в одной точке;
- `Segment3D` — пересечение по общему подотрезку.

### 2. Ранняя отсечка через AABB (Axis-Aligned Bounding Box)

Перед выполнением векторных операций строится параллелепипед с расширением на величину допуска `tol`. Отсечение непересекающихся пар происходит всего за 6 сравнений без делений и тригонометрии.

### 3. Численная устойчивость

- **Безразмерные допуски**: проверка коллинеарности нормализована на длины отрезков. Это исключает ложные срабатывания на микро- и макро-масштабах.
- **Исключение деления на ноль**: алгоритм гарантирует отсутствие исключений.

## Структура проекта

```text
ledas/
├── include/
│   ├── vector3d.h      # 3D-вектор: координаты, векторная арифметика
│   ├── segment3d.h     # 3D-отрезок: start и end
│   ├── aabb.h          # Axis-Aligned Bounding Box для быстрой отсечки
│   └── maths.h         # API функции Intersect и векторных операций
├── src/
│   ├── vector3d.cpp    # Реализация операторов Vector3D
│   ├── aabb.cpp        # Проверка пересечения габаритных боксов
│   └── maths.cpp       # Геометрическое ядро пересечения
├── tests/
│   ├── CMakeLists.txt  # Подключение GoogleTest
│   └── test_maths.cpp  # 34 модульных и стресс-теста
├── main.cpp            # Консольная демонстрационная программа
└── CMakeLists.txt      # Корневая конфигурация сборки
```

```bash

./build/ledas_demo
```

## 🧪 Тестирование

Набор тестов в [`tests/test_maths.cpp`](tests/test_maths.cpp) включает **34 сценария**:

- **Векторная алгебра**: скалярное, векторное произведение.
- **AABB**: пересекающиеся, раздельные и касающиеся объёмы.
- **Пересечения под углами**: 2D-крест, наклонные 3D-плоскости, копланарные непересекающиеся.
- **Касания вершинами**: L-стыки (все комбинации) и T-стыки.
- **Коллинеарность**: раздельные, касание концом, частичный overlap, вложенность, идентичность, противоположные направления.
- **Скрещивающиеся прямые**: разделение на расстоянии $0.5 \cdot tol$ (есть пересечение) и $2.0 \cdot tol$ (нет пересечения).
- **Вырожденные отрезки**: точка-точка, точка на отрезке, точка вне отрезка.
- **Масштаб**: макро-координаты ($10^6$) и микро-координаты ($10^{-5}$ при $tol = 10^{-9}$).
- **Стресс-тестирование**: 2 000 случайно сгенерированных гарантированно пересекающихся пар с верификацией геометрических инвариантов.

Запуск тестового набора:

```bash
ctest --test-dir build --output-on-failure
```
